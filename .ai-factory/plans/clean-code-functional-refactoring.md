## Настройки

- Testing: yes — сначала регрессионные автотесты существующего поведения, затем рефакторинг. В `composer.json` установлен PHPUnit; Pest не добавлять только ради стиля тестов. Новые тесты писать в доступном стеке, переход на Pest согласовать отдельно при необходимости.
- Logging: verbose — подробные структурированные DEBUG записи на границах сценариев и шагов, INFO для важных изменений, WARNING/ERROR для отказов; уровень управляется конфигурацией Laravel. Не записывать содержимое документов, файлов, сообщений, персональные данные, токены и полные пути пользователя. Чистые функции форматирования и построения путей не засорять логами: логировать вызов сценария и результат операции.
- Docs: yes — обновлять документацию при изменении поведения, контрактов API или порядка внешних операций; после реализации пройти документационный checkpoint.
- Совместимость: PHP 8.1, Laravel 10; сохранить JSON ответы, коды статуса, права доступа, имена файлов, схему Media, события, порядок операций БД/Storage и формат DOCX/PDF, если отдельный пункт не обосновывает изменение поведения.
- Проверки в рамках этого планирования не запускались по `AGENTS.md`. При реализации запускать тесты и анализаторы только по прямому запросу пользователя; написание автотестов входит в задачи.

## Принцип отбора

Ориентиры из Clean Code Роберта Мартина: один уровень абстракции внутри метода; маленькие методы с одной задачей; понятные имена, раскрывающие намерение; небольшое число аргументов; отсутствие дублирования, скрытого состояния, флагов поведения и необъяснимых литералов; локальная обработка ошибок без смешения с основным сценарием. Это эвристики, а не механические лимиты строк или аргументов. Четыре аргумента сами по себе не доказывают дефект; вводить объект параметров только когда он выражает устойчивое понятие. Длина класса с `@OA` docblock также не равна сложности его методов.

Предыдущий [план](crm-refactoring-audit.md) отметил 32 задачи завершёнными и устранил ряд рисков. Новый проход работает с **оставшейся читаемостью и разделением обязанностей**; не возвращает уже исправленные дефекты. Просмотрены текущие сервисы, 28 API контроллеров, модели, observers, jobs, маршруты и существующие тесты. Каталогов `app/Actions` и `app/Repositories` сейчас нет: создавать их ради паттерна не требуется. Перед правкой каждого модуля сверить его фактические вызовы и тесты. Статический обзор показывает кандидатов, а не доказанные ошибки рантайма.
