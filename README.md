# CRM Backend

Этот репозиторий — портфолио-проект для поэтапной работы над чистотой и качеством кода бэкенда CRM-системы. Я буду постепенно разбирать существующий код, проводить рефакторинг, оптимизацию и исправлять найденные ошибки — самостоятельно и с помощью ИИ.

## Статус проекта

Работа только началась. Проект не завершён и не предназначен для использования в качестве готовой CRM-системы.

В кодовой базе ещё много участков, до которых я пока мог не дойти. Поэтому при знакомстве с проектом лучше смотреть на историю изменений: она показывает, что именно и по каким причинам менялось. Текущее состояние всего кода пока не отражает завершённый результат.

## Диагностика
