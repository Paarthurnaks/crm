# CRM Backend

## Стек и локальный запуск

Приложение использует PHP 8.5 и Laravel 13. Зафиксированные версии библиотек находятся в `composer.lock`. Образ PHP собирается из `docker/php85` на основе конфигурации Laravel Sail; в нём оставлены необходимые для API PHP, Composer, Node.js и клиенты баз данных.

Для локального запуска с PostgreSQL 15 и Redis используйте PowerShell:

```powershell
docker compose -f docker-compose-local.yml up -d --build
docker compose -f docker-compose-local.yml exec -T laravel.test composer install
```

Основной `docker-compose.yml` запускает MySQL 8 вместо PostgreSQL. Выбирайте один Compose-файл и настройте подключение к соответствующей базе данных в локальном окружении. Миграции выполняйте отдельно после проверки подключения и резервной копии данных. Для установки зависимостей на хосте требуется PHP 8.5 со всеми расширениями из `composer.json`; при другой версии PHP запускайте Composer в контейнере.

Этот репозиторий — портфолио-проект для поэтапной работы над чистотой и качеством кода бэкенда CRM-системы. Я буду постепенно разбирать существующий код, проводить рефакторинг, оптимизацию и исправлять найденные ошибки — самостоятельно и с помощью ИИ.
